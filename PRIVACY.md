# Política de Privacidad - Universal Downloader

1. **Recopilación de Datos**: Universal Downloader no recopila, almacena ni comparte ningún tipo de dato personal de sus usuarios.
2. **Procesamiento Local**: Todos los enlaces de video introducidos se procesan exclusivamente de forma local en el equipo del usuario para facilitar las descargas mediante el motor yt-dlp.
3. **Gestión de Cookies**: El archivo `cookies.txt`, en caso de ser utilizado para contenido privado, se maneja de forma estrictamente local y nunca es transmitido a servidores externos.
4. **Seguridad**: No se requiere registro ni creación de cuenta para utilizar las funciones de la aplicación.
