# Política de Privacidad - Universal Downloader

Esta Política de Privacidad describe cómo se maneja la información en la aplicación Universal Downloader.

### 1. Recopilación de Datos
Universal Downloader es una aplicación de escritorio de uso local. **No recopilamos, almacenamos ni compartimos ningún tipo de dato personal** de los usuarios en servidores externos.

### 2. Procesamiento de Enlaces
Los enlaces multimedia introducidos por el usuario se procesan exclusivamente de forma local en su dispositivo para facilitar la descarga a través del motor de código abierto `yt-dlp`.

### 3. Uso de Cookies
Si el usuario utiliza la función de carga de `cookies.txt` para acceder a contenido privado (como Reels de Instagram o videos de Loom), dicho archivo se maneja de forma estrictamente local. Estos datos de sesión nunca son transmitidos fuera del entorno de ejecución de la aplicación en el equipo del usuario.

### 4. Transparencia
No se requiere registro, inicio de sesión ni creación de perfiles para utilizar las funciones de la herramienta.
